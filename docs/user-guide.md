## 界面

底部导航有四页：**拨号**、**记录**、**通讯录**、**设置**。快捷键从拨号页的快捷键按钮进入，通话中可从通话界面打开。

有通话进行时，其它页面上显示返回通话的横幅，位置可在 **设置 → 外观 → 通话横幅位置** 中选择（顶部 / 底部，默认底部）。

## 账号

**设置 → SIP 账号**。最多 100 个账号。列表显示已注册、失败、停用数量，可搜索。

### 字段

| 字段 | 说明 |
| --- | --- |
| 账号名称（可选） | 仅在本机使用，不发送给服务器；最多 30 个字符，不能与其它账号重名（不区分大小写）。快捷键可按名称固定线路 |
| 用户名 | 必填 |
| 端口 | 留空则使用传输协议的默认端口，或域名 DNS 记录中的端口 |
| 域名 / 服务器 | 必填，主机名、IPv4 或 `[IPv6]` |
| 密码 | 编辑已有账号时留空表示不修改 |
| 显示名称（可选） | |
| 传输协议 | UDP / TCP / TLS。端口为空或为默认值时随协议切换（UDP、TCP 为 5060，TLS 为 5061） |

**高级设置**（折叠）：

| 字段 | 说明 |
| --- | --- |
| 认证用户名（可选） | 与用户名不同时填写 |
| 代理服务器（可选） | `主机[:端口]`，注册与呼叫发往此处；留空则发往域名 |
| 备用代理服务器（可选） | `主机[:端口]`，不能与主服务器相同。主服务器无法连接时切换到备用服务器，主服务器恢复且没有通话时切回。列表中正在使用备用服务器的账号标注“备用服务器” |
| DNS 服务器（可选） | `IP[:端口]`（IPv4，默认端口 53）。本账号的服务器地址在此查询，而不使用系统 DNS |
| 注册有效期（秒） | 60–86400，默认 3600 |
| 订阅语音留言 | 默认关闭。开启后向 PBX 订阅留言通知（SUBSCRIBE）；PBX 主动推送时无需开启 |
| 启用此账号 | 停用的账号不注册，也不用于呼出 |

输入时：`sip:` / `sips:` 前缀会被去掉；用户名中输入 `user@domain` 且域名为空时自动拆分；域名后写的 `:端口` 移入端口字段；中文全角冒号视同半角。同一用户名与域名的账号不能重复。

账号编辑页可 **设为默认账号** 或 **删除账号**。删除后，固定使用该线路的快捷键改为拨出时选择线路。

### TLS 与 SRTP

传输协议选 TLS 时，服务器证书须由受信任的 CA 签发。私有 CA 的根证书在 **设置 → TLS 与 CA 证书** 中导入，见[设置](#tls-与-ca-证书)。媒体加密（SRTP）在同一页面设置。

### 批量导入

账号列表右上角的导入按钮。粘贴文本或选择 CSV 文件（文件只读取前 512 KB），每行一个账号：

```text
用户名,密码,域名[,传输协议[,显示名称[,代理服务器[,账号名称]]]]
```

- 传输协议：`udp` / `tcp` / `tls`，留空为 `udp`
- 空行和以 `#` 开头的行被忽略；文件开头的 BOM 被忽略
- 字段含逗号时用双引号包围，字段内的双引号写作 `""`
- 每行按与手工添加相同的规则校验；有误的行逐行报告（最多列出 8 行），其余行照常导入；超过 100 个账号上限的行被跳过

示例：

```text
# 用户名,密码,域名,传输协议,显示名称,代理服务器,账号名称
1001,"pass,word",pbx.example.com,tls,前台,,前台
1002,pw1002,pbx.example.com
```

## 拨号与通话

### 拨号页

- 顶部选择呼出账号，或“跟随默认账号”
- 号码可通过拨号盘或键盘输入，支持分机号和 SIP 地址
- 呼叫按钮旁有视频呼叫按钮（视频通话开启时）和快捷键按钮
- 话务功能按钮打开功能面板，见[功能码](#功能码)
- 免打扰开启时显示“免打扰已开启”，点按关闭；有新留言时显示“N 条新留言”，点按拨打语音信箱功能码
- 横屏时，账号、提示、号码和呼叫按钮在一侧，拨号键在另一侧

### 通话界面

| 控件 | 说明 |
| --- | --- |
| 静音 | |
| 键盘 | 发送 DTMF |
| 音频路由 | 听筒、扬声器、蓝牙、有线耳机 |
| 保留 / 恢复 | |
| 转接 | 输入目标后选择 **盲转** 或 **咨询转** |
| 驻留 | 将通话盲转到驻留功能码，PBX 播报车位号后挂断；有第二路通话时不可用 |
| 切换 | 在当前通话与保留的通话之间切换 |
| 合并 | 以当前通话和保留的通话开启会议室，见[会议室](#会议室) |
| 快捷键 | 打开快捷键面板 |
| 视频 | 为通话添加或移除视频，见[视频通话](#视频通话) |
| 会议室（左上角） | 开启会议室，见[会议室](#会议室) |
| 录音（右上角） | 开始 / 停止录音，录音中显示已录时长；视频通话时与摄像头按钮在顶部同一行。见[通话录音](#通话录音) |

**咨询转**：当前通话被保留，先呼叫目标；接通后点按“完成转接”把保留的一方转给目标。

**监听 / 耳语 / 强插**：通过功能码发起的班长通话，在通话界面可在三种模式间切换，切换时向 PBX 发送 DTMF `4` / `5` / `6`，只发给该通话。

用户界面最多同时显示两路通话（当前通话，加一路保留或等待中的通话），会议室除外。

横屏时，通话中的键盘显示在控制按钮一侧，关闭前遮住挂断按钮（与竖屏相同）。

### 呼叫等待

已有通话时来电，界面显示“新来电”，可 **拒绝新来电** 或 **保留当前通话并接听**。在 **高级设置** 中关闭呼叫等待后，此时的来电按忙线拒绝（设置了遇忙前转时则前转）。

### 对讲

带有自动接听请求的来电被识别为对讲呼叫，识别的 SIP 头：

- `Call-Info` 含 `answer-after=`
- `Alert-Info` 含 `alert-autoanswer`、`auto answer` 或 `intercom`
- `Answer-Mode: Auto`

开启 **设置 → 对讲与自动接听 → 自动接听对讲呼叫**（默认关闭）后立即自动接听，只作用于对讲呼叫。应用不在前台时先显示通话界面再接听（Android 不允许后台应用使用麦克风）。已有通话（含保留的通话）或会议室时，对讲呼叫也不自动接听。**对讲使用扬声器**（默认开启）决定对讲是否走扬声器。主动发起对讲使用功能码，见[功能码](#功能码)。

### 自动接听

**设置 → 对讲与自动接听 → 常规呼叫 → 自动接听**（默认关闭）作用于非对讲来电，与对讲的开关互不影响。开启后可选 **自动接听时间**：立即 / 3 / 5 / 10 / 20 / 30 秒（默认 3 秒），从开始振铃计时，以语音方式接听。

- 只接听没有其它通话时的来电；通话中到来的第二路来电不会自动接听，前一路结束后也不会
- 免打扰、拒接匿名来电和前转仍在振铃前生效；无应答前转与自动接听同时设置时，先到时间者生效
- 应用不在前台时先显示通话界面，界面显示且时间已到才接听

## 来电处理

来电按以下顺序处理，命中即止：

| 顺序 | 条件 | 结果 |
| --- | --- | --- |
| 1 | 免打扰开启，方式为“软件” | 本机拒接 |
| 2 | 主叫隐藏号码且开启“拒接匿名来电” | 以 SIP 433 Anonymity Disallowed 拒接 |
| 3 | 设置了无条件前转 | 前转 |
| 4 | 已有通话（含保留的通话）或会议室 | 有遇忙前转则前转；否则呼叫等待开启且无第二路通话时作为等待来电；否则按忙线拒接 |
| 5 | 其它 | 振铃；设置了无应答前转时，振铃超过等待时间后前转 |

等待来电不会自动接听（对讲呼叫也不例外）；会议室开启时，等待来电只能 **加入会议室** 或 **拒接**。

前转由本机以 SIP 重定向完成，仅在应用运行并已注册时有效。前转目标为纯号码时补全为来电账号的域名。

**免打扰方式**（高级设置）：

- **软件**（默认）：本机拒接全部来电
- **服务器**：开关免打扰时拨打 PBX 的“开启免打扰” / “关闭免打扰”功能码，由 PBX 处理来电。两个功能码都设置后才能选择；切换方式时免打扰重置为关闭

## 会议室

会议室把多路通话汇集到本机：本机混音，PBX 上每个成员是一路普通通话（信令总是经过 PBX；媒体也经过 PBX，除非 PBX 使用直连媒体）。会议室仅支持语音。

- **开启**：通话接通后点按通话界面左上角的 **会议室**，当前通话（及保留的通话）进入会议室；**合并** 同样开启会议室。视频通话中先确认“会议室仅支持语音，视频将关闭。”
- **人数**：默认最多 30 名成员（不含本机），在 **设置 → 高级设置 → 会议室 → 会议室人数上限** 中设置为 2–30；配置由远程下发时只读。标题旁显示人数与上限，如 `3/30`；已满时 **添加成员** 为灰色
- **添加成员**：从“最近通话”、“通讯录”（第一个启用的 LDAP 通讯录）或“快捷键”（速拨类型）中选择，或输入号码后添加，可多选，然后点按 **呼叫**。已在会议室中的号码不重复呼叫
- **呼叫**：本机同时最多呼叫 3 个成员，其余显示“等待呼叫”，依次呼叫
- **成员**：每行显示状态（等待呼叫、呼叫中、振铃、已接通、已保留），已接通的成员另有三格通话质量；每个成员可单独挂断
- **结束**：**结束会议** 挂断全部成员，会议室中多于一名成员时先确认（从通知中挂断时也先确认）。最后一名成员离开时会议室结束
- **新来电**：只能 **加入会议室** 或 **拒接**
- **其它应用占用声音**（例如手机网络来电）：本机离开会议室的声音，显示“已暂离”，其他成员继续通话；点按 **返回会议室** 回到会议室
- PBX 结束全部通话或网络中断时，会议室正常结束；会议期间应用进程被系统结束时，会议室随之结束
- **限制**：会议室中没有键盘、转接、驻留、录音和视频；开启会议室时正在进行的录音结束，成员的视频请求被拒绝。监听、耳语、强插的通话不能开启或加入会议室，这几项和强拆的功能码也不能作为成员呼叫。转接或驻留进行中时不能开启会议室

### 呼叫失败

PBX 拒绝呼叫时，成员行显示原因。返回 503，或连续 3 次失败（中间没有应答）时，停止呼叫其余成员，它们显示同样的原因。不自动重试：每行可 **重拨** 或 **移除**。PBX 给出 `Retry-After` 时，到时间前重拨提示“请稍后重试”。

| 提示 | 原因 |
| --- | --- |
| 线路已满 | 503；会议室中已有成员时，连续忙或拒绝，或某成员接通后 8 秒内被对方挂断（FreePBX 在分机的并发呼叫数达到上限时会这样），见[常见问题](faq.md#会议室成员显示线路已满) |
| PBX 拒绝 | 403 |
| 忙 | 486、600 |
| 暂时无法接通 | 480 |
| 媒体协商失败 | 488 |

### 质量提示

会议期间，应用检测本机（处理器、温度、内存）和每个成员的线路（丢包、抖动、往返时延），可能影响会议时在标题旁显示提示：“设备温度过高”“设备负载过高”“内存不足”“网络质量差”，同时有多项时显示排在前面的一项。点按提示查看测量值：处理器、最忙线程、设备温度、内存，以及线路较差的成员（最多 5 个）的上行 / 下行丢包、抖动和往返时延。成员的线路较差一段时间后，其三格质量变为琥珀色。

## 视频通话

**设置 → 视频通话**（默认开启）。关闭后应用只做语音通话，并拒绝对方添加视频的请求。

- 发起：拨号页的视频呼叫按钮；接听：来电界面选择“视频接听”或“语音接听”
- 通话中：“视频”按钮添加或移除视频；对方请求开启视频时显示提示，可 **拒绝** 或 **开启**，开启前摄像头不工作
- 摄像头权限在首次使用视频时申请；未授权时只接收对方画面
- 摄像头只在通话界面处于前台时工作，离开界面时改为发送静态画面
- 可切换前后摄像头、关闭 / 打开摄像头；对方画面按原比例显示，可在“显示完整画面”和“铺满屏幕”之间切换。这些按钮与录音按钮在顶部一行
- 收到对方画面后，控制按钮在约 4 秒无操作后隐藏（系统无障碍设置的操作时间更长时按该时间），点按画面显示或隐藏；打开键盘或面板、有提示或新来电、使用屏幕阅读器时不隐藏
- 自己的画面是一个小窗：可拖动，松手后停靠在左侧或右侧边缘（甩动时停靠在甩向的一侧）；靠近顶部或底部时随控制按钮的显示和隐藏上下移动；点按小窗交换两个画面。位置会被记住，转动手机和之后的通话中保持。屏幕阅读器中可用的操作：“交换画面”“移到左侧”“移到右侧”“上移”“下移”
- 视频开始时，若当前使用听筒且未连接耳机或蓝牙，声音切换到扬声器
- 通话界面支持横屏
- 会议室中不能使用视频

清晰度与帧率在 **设置 → 编码** 中设置：

| 项 | 选项 | 默认 |
| --- | --- | --- |
| 清晰度 | 240p / 480p / 720p / 1080p | 480p |
| 帧率（帧/秒） | 自动 / 15 / 24 / 30 | 自动 |

选择固定帧率时，上行码率按清晰度和帧率限制（30 帧时 240p 为 256 kbit/s、480p 为 768、720p 为 1536、1080p 为 3072，另加 100 kbit/s 音频余量，帧率较低时按比例减少）；“自动”由 SIP 协议栈决定码率。实际发送的画面仍取决于摄像头、编码和网络。

## 功能码

**设置 → 功能码**。功能码是 PBX 拨号计划中的拨号串，须与 PBX 一致。只允许 `0-9`、`*`、`#`。**恢复默认** 恢复下表默认值（与 `testenv/` 中的示例 Asterisk 拨号计划一致）。

| 功能 | 默认 | 拨号方式 | 用途 |
| --- | --- | --- | --- |
| 对讲 | `*80` | 功能码 + 分机 | 呼叫对方并请求其自动接听 |
| 监听 | `*91` | 功能码 + 分机 | 旁听对方通话 |
| 耳语 | `*92` | 功能码 + 分机 | 只让被监控分机听到 |
| 强插 | `*93` | 功能码 + 分机 | 加入对方通话 |
| 强拆 | `*94` | 功能码 + 分机 | 强制挂断对方通话；需连续点按两次确认 |
| 指定代接 | `**` | 功能码 + 分机 | 代接指定分机的来电 |
| 同组代接 | `*8` | 直接拨打 | 代接同组来电 |
| 驻留 | `700` | 通话中盲转到此号码 | 通话界面的“驻留” |
| 语音信箱 | `*97` | 直接拨打 | |
| 开启免打扰 | `*78` | 直接拨打 | 免打扰方式为“服务器”时使用 |
| 关闭免打扰 | `*79` | 直接拨打 | 同上 |

功能码留空即表示不使用该功能：对应入口显示为灰色，点按时提示“未配置“功能名”功能码”。

话务功能面板（拨号页的话务功能按钮，或通讯录、通话记录中某条目的菜单）列出对讲、监听、耳语、强插、强拆、指定代接、同组代接、语音信箱；从拨号页打开时需输入目标分机。

## 快捷键

类似桌面话机的功能键，从拨号页的快捷键按钮或通话界面打开。最多 2000 个。

### 类型

| 类型 | CSV 写法 | 空闲时 | 通话中 |
| --- | --- | --- | --- |
| 速拨 | `speed` | 呼叫号码 | 保留当前通话并呼叫号码 |
| 盲转 | `bxfer` | 呼叫号码 | 把对方直接转给号码 |
| 咨询转 | `axfer` | 呼叫号码 | 保留当前通话并呼叫号码，之后完成转接 |
| 发送按键 | `dtmf` | — | 向当前通话发送按键，仅限 `0-9 * #` |
| 呼叫前转 | `forward` | 开关“无条件前转到该号码” | 同左 |
| 免打扰 | `dnd` | 开关免打扰（方式为“服务器”时拨打对应功能码） | 同左 |

PBX 通过功能码提供的功能（对讲、广播、驻留、代接、语音信箱等）使用“速拨”类型，号码填功能码，例如 `*801005`。

### 字段与限制

| 字段 | 限制 |
| --- | --- |
| 名称 | 最多 24 个字符；留空时用号码（或类型名）代替 |
| 号码 | 最多 128 个字符，不能含空格；免打扰类型没有号码 |
| 类型 | 见上表 |
| 线路 | “拨出时选择”或“固定线路”（账号名称或 `user@domain`）。固定的账号被删除或停用时，按下按键会要求选择线路 |
| 图标 | 默认随类型；可选 32 种 |
| 分类 | 最多 16 个字符，不区分大小写；“全部”“未分类”“新建分类”不可用作分类名 |

账号改名或删除时，固定使用该账号的快捷键随之更新。

### CSV 导入导出

菜单中的 **批量导入** 与 **导出为 CSV**。每行一个按键：

```text
名称,号码[,类型[,分类[,线路[,图标]]]]
```

- 类型：`speed` / `bxfer` / `axfer` / `dtmf` / `forward` / `dnd`，也接受中文类型名；留空为 `speed`
- 线路：账号名称或 `user@domain`；留空则拨出时选择
- 图标：`phone` `person` `group` `star` `home` `office` `store` `reception` `support` `speaker` `meeting` `door` `lock` `key` `garage` `car` `elevator` `security` `camera` `bell` `alarm` `medical` `fire` `food` `hotel` `warehouse` `factory` `school` `repair` `computer` `delivery` `light`，也接受中文图标名；留空随类型
- 引号、注释行、文件大小等规则与[账号批量导入](#批量导入)相同；超过 2000 个上限的行被跳过

示例：

```text
前台,1001,speed,常用,,reception
对讲仓库,*801005,speed,对讲,,warehouse
开门,#9,dtmf,门禁,,door
转总机,1000,bxfer,转接
```

配置由远程下发时的快捷键规则见[远程配置](remote-configuration.md#用户保留的内容)。

## LDAP 通讯录

**设置 → 话务功能 → LDAP 通讯录**，或通讯录页右上角。最多 50 个通讯录。通讯录页需要至少一个 SIP 账号。

| 字段 | 说明 |
| --- | --- |
| 名称（可选） | 最多 40 个字符，不能重名；留空时以服务器地址显示 |
| 服务器地址 | `主机[:端口]`，默认端口 389；可写作 `ldap://主机:端口`。不支持 `ldaps://` |
| 搜索基准 | 必填（Base DN） |
| 加密 | 不加密 / StartTLS。StartTLS 要求服务器地址为域名，不能是 IP 地址；证书须由受信任的 CA 签发 |
| 登录 | 账号（用户名为 Bind DN，加密码）或匿名 |
| 线路 | 全部线路，或某个账号：该账号的通话优先用此通讯录显示姓名，从此通讯录呼出时使用该账号 |
| 来电显示姓名 / 去电显示姓名 | 默认开启 |
| 姓名属性 | 默认 `cn sn`，空格或逗号分隔；`sn+givenName` 表示由多个属性组成 |
| 号码属性 | 默认 `telephoneNumber mobile` |
| 最大结果数 | 1–1000，默认 50 |
| 过滤器 | 自动（由属性生成“包含”匹配）或自定义。自定义过滤器中 `%` 代表搜索内容并按前缀匹配，例如 `(cn=%)` 匹配以搜索内容开头的姓名，`(cn=*%)` 匹配包含它的姓名；须包含 `%` |
| 启用此通讯录 | |

- 搜索内容只含数字和 `+*#-()` 及空格时按号码搜索，否则按姓名搜索
- 来去电显示姓名时，先查该线路的通讯录，再查“全部线路”的通讯录
- 服务器返回的条目保存在本地缓存中，搜索时先显示缓存中的匹配；服务器尚未响应或没有结果时保留这些匹配，并标注“来自本地缓存”。缓存上限 100 MB，超过 90 天未被服务器返回的条目被删除。LDAP 列表页的“本地缓存”可查看用量并清空
- 搜索结果达到最大结果数时显示“仅显示前 N 条”

## 通话记录

“记录”页显示最近 500 条通话：呼出、呼入、未接来电、未接通。每条可 **回拨**，菜单中有 **添加到快捷键**、**话务功能…**、**删除记录**。右上角可清空全部记录（不可恢复）。号码在通讯录中有姓名时显示姓名。

## 通话录音

通话界面右上角的录音按钮开始或停止录音，录音中按钮显示红点和已录时长。开始和停止时不播放提示音，也不通知对方。同一通话多次开始、停止，录音保存为一个文件（停止期间不录）。保留、恢复通话和熄屏不影响录音，通话结束时录音结束。

- 录下双方的声音（混合为单声道）；视频通话只录声音
- 每路通话单独录音，录音按钮作用于当前通话
- 会议室不能录音：开启会议室时正在进行的录音结束，会议室中没有录音按钮
- 由 PBX 转来（REFER、Replaces）的通话不能录音

**设置 → 话务功能 → 录音**：

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 通话录音 | 关闭后通话界面不显示录音按钮 | 开 |
| 默认录音 | 每路通话接通即开始录音，可用按钮停止和继续 | 关 |
| 保留条数 | 100 / 200 / 500 / 1000 | 500 |
| 录音文件 | 打开录音列表 | — |

录音保存在应用私有目录，最多保留“保留条数”条且总大小不超过 2 GB，超出时先删除最早的录音（录音结束时和应用启动时检查）。应用异常退出时未完成的录音在下次启动时整理保存，无声音的文件删除。

格式为 AAC-LC 单声道 `.m4a`，采样率随通话编码（如 Opus 为 48 kHz，G.711 为 8 kHz），码率 32 kbit/s（8 kHz 时 24 kbit/s），约每分钟 240 KB。通话中先记录为 WAV，通话结束后转换；转换失败时保留 WAV。

**录音文件** 页按时间从新到旧列出录音，显示对方、呼入 / 呼出、开始时间、时长、大小：

- 时间筛选：全部、今天、7 天、30 天、自定义日期范围；列表上方显示条数和总大小
- 点按播放 / 停止
- 菜单：**导出**（选择保存位置）、**删除**
- 长按进入多选；顶栏 **导出** 导出所选录音（未选择时导出当前筛选结果）到所选文件夹，**删除** 删除所选录音（需确认）
- 导出文件名为 `{开始时间}_{号码}.m4a`，如 `20261117-143005_1001.m4a`

远程配置下“录音文件”页和“保留条数”仍由用户使用和设置，“通话录音”和“默认录音”由平台下发。

**自适应速率控制**默认关闭。开启后 SIP 协议栈按网络情况调整码率和打包时长。PBX 通常不提供 RTCP 反馈（AVPF），此时 SDK 使用基础控制器，在检测到丢包或往返时延加倍时把音频打包时长逐步加长到 100 ms，已有报告在 Asterisk 后方此时对端变为无声。见[常见问题](faq.md#通话一段时间后无声)。

**客户端名称（User-Agent）**：最多 120 个可打印 ASCII 字符，首尾不能包含空格。留空时发送 `LinphoneSDK/{SDK 版本} SipLink/{应用版本}`：SDK 名称在前，因为有的服务只接受以已知客户端名称开头的 User-Agent。修改后账号自动重新注册。

### TLS 与 CA 证书

- **导入 CA 证书**：支持 PEM（可含多个证书）、DER、PKCS#7，文件不超过 1 MB。导入后账号重新注册。证书列表显示签发者、有效期，非 CA 证书和已过期证书会标注
- 导入的 CA 与 SIP 协议栈自带的根证书一起使用，同时用于 SIP over TLS 和 LDAP StartTLS。LDAP 已建立过加密连接后再更换 CA，需重启应用才对 LDAP 生效（应用会提示）
- **校验服务器证书**、**校验主机名**：默认开启。关闭校验存在被窃听风险
- **媒体加密（SRTP）**：关闭（默认）/ 优先 / 强制

### 编码

音频编码和视频编码分别列出，用箭头调整优先级，开关启用。至少保留一种音频编码；视频通话开启时至少保留一种视频编码。**恢复默认** 恢复 SDK 默认的编码设置。视频的清晰度与帧率见[视频通话](#视频通话)。

## 电池策略

应用不使用推送通知，来电依赖应用在后台保持注册。

- **后台保持在线**（默认开启）：运行一个前台服务，通知栏显示“SipLink 运行中”及“已注册 / 已启用”账号数。开机和应用更新后自动启动。关闭后，应用进程被系统结束时将收不到来电
- **电池优化**：打开系统的电池优化设置，建议对 SipLink 关闭电池优化
- **锁屏显示来电**：Android 14 起，来电在锁屏上显示通话界面需要“全屏通知”权限，未授权时锁屏来电只显示通知。未授权时启动应用会提示，可选“不再提醒”

通话中，贴近耳朵且使用听筒时屏幕熄灭（视频通话时不熄屏）。

## 更新

“自动检查更新”开启时，应用每次启动或回到前台时在后台检查 GitHub 上的最新发布版本，不影响使用；距上次检查不足 1 分钟时跳过。在 **设置 → 关于** 点按“版本”行可随时手动检查。

检查失败时不弹出提示，只在版本行显示“更新检查失败”或“请求过于频繁”。GitHub 返回频率限制后，在其给出的解除时间之前不再请求，见[常见问题](faq.md#检查更新失败)。

发现新版本时，设置页标签显示提示点，关于行显示“有新版本”，在关于页点按版本行可查看更新说明，选择 **跳过此版本** 或 **下载并安装**：

1. 应用下载与本机 ABI 匹配的 APK，显示进度，可 **取消下载**；离开页面不影响下载
2. 下载完成后核对大小、SHA-256 摘要（发布提供时）和包名，不符时显示“下载失败”
3. 点按 **安装** 交给系统安装程序，由用户确认。首次安装需在系统设置中允许 SipLink“安装未知应用”，允许后返回即继续

发布中没有与本机 ABI 匹配的 APK 时，按钮为 **前往下载页**，在浏览器中打开发布页面。下载的文件在下次启动时删除。联网细节见[隐私与权限](privacy.md)。
